## 🛠️ Database Setup Configuration

To run this application locally, you must have a MySQL server running. Follow these configuration details:

### 1. Create the Database Schema
Open your MySQL Command Line Client or workbench and execute:

```sql
CREATE DATABASE ticket_system;

```

### 2. Required Database Tables Setup

Execute the following queries to create the structured relational layout:

```sql
USE ticket_system;

-- Create Users Table
CREATE TABLE users (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL
);

-- Create Events Table
CREATE TABLE events (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(100) NOT NULL,
    available_tickets INT NOT NULL CHECK (available_tickets >= 0)
);

-- Create Bookings Table
CREATE TABLE bookings (
    id VARCHAR(36) PRIMARY KEY,
    user_id BIGINT,
    event_id BIGINT,
    booking_status VARCHAR(20) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id),
    FOREIGN KEY (event_id) REFERENCES events(id)
);

```

### 3. Insert Initial Mock Bootstrap Data

You need at least one event and one user to execute bookings cleanly:

```sql
-- Seed dummy customer
INSERT INTO users (id, name, email) VALUES (1, 'Test User', 'user1@example.com');

-- Seed target concert/event with inventory
INSERT INTO events (id, title, available_tickets) VALUES (1, 'Rock Concert 2026', 100);

```

## ⚙️ Spring Boot Configuration

Ensure your `src/main/resources/application.properties` file points to your local database instance:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/ticket_system?useSSL=false&serverTimezone=UTC
spring.datasource.username=YOUR_MYSQL_USERNAME
spring.datasource.password=YOUR_MYSQL_PASSWORD
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true

```
